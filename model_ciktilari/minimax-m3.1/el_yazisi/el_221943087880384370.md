# SATIR SONUNA SİĞMAYAN SÖZCÜKLER
</header>

<figure/>

Yazı yazarken satır sonuna sığmayan kelimeler hecelerinden bölünür. Satır sonuna sığmayan kelimeleri kısa fiil (-) kullanarak hecelerine ayırıp alt satıra yazarız.

Örnek: ---tel- efon → Yanlış

---te- lefon → Doğru

---tele- fon → Doğru

<figure/>

Kelimeler satır sonunda veya satır başında tek harf olacak şekilde bölünmez.

Örnek: ---o- kulum → Yanlış

---oku- lum → Doğru

---elmay- ı → Yanlış

---elma- yı → Doğru

<figure/>

Kesme işareti: satır sonuna geliş sadece kesme işareti kullanılır. Kısa eğri kullanılmaz.

Örnek: ---Denizli' nin → Yanlış

---Denizli' nin → Doğru
