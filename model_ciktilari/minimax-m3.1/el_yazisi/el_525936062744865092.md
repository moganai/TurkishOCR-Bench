✓ Konusunun devlet idaresi oluşturur.

## Özellikleri

✓ Kamu hukuku dalıdır.
✓ Geniş bir hukuk dalıdır.
✓ Dinamik bir hukuk dalıdır.
✓ Tedvin (modifiye) edilmiştir. (Dağınık)
✓ İgtihat hukukudur. (uygulamalara dayanır.)
✓ Stateli hukukudur. (Kuralsaldır.)
✓ Uyuşmazlıkları idari yargıda çözümlenir.

## İdari Fonksiyon

✓ Gündelik gereksinimleri karşılamak
✓ Amaç, kamu yararının sağlanması
✓ Üstün yetki ve ayrıcalıklara dayanır. (kamu gücü)
✓ İdari işlem yada eylem yapmak.
✓ Re'sen (kendiliğinden) harekete geçer.
✓ Süreklidir.
✓ Tüm bireyleri kapsar.

## İdare Hukukunun Kaynakları

✓ Anayasa
✓ Kanun, KHK, m.a.a
✓ Tüzük
✓ Yönetmelik
✓ Bilimsel görüşler
✓ İçtihatlar

Örf ve adet hukuku idare hukukunun kaynağı değildir.
