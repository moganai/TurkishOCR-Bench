# İsim (ad)
- kökü → isim
- görevi → etkilenmek
  - oda, çanta, kalem, Alya

# Sıfat
- kökü → isim
- görevi → ismi nitellemek, belirtmek
- ismin önüne gelir
  - güzel, arikin, kısa, uzun, besinci

# Zamir
- kökü → isim
- görevi → ismin yerini tutar
  - ben, benim, o, onlar, şu, bu

# Zarf
- kökü → isim
- görevi → fiil, fiilimsi, sıfat ettirmek
  - güzel, büyük, hızlı, neden, niye

# Edat
- kökü → isim
- görevi → kelimeler arası ilgi kurar
  - ile, gibi, -e karşı, -den ötürü

# Bağlaç
- kökü → isim
- görevi → bağlamak
  - ve, ile, veya, lakin, çünkü, de

# Ünlem
- görevi → duygu yansıtmak
  - hışt, haydi, vah vah, of, hay

# Fiil
- kökü → fiil
- görevi → eylemleri belirtmek
  - gelmek, gitmek, almak, attırmek
