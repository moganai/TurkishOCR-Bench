# Canlıların ortak özellikleri

1: Hücresel yapı  
a) Hücre sayısına göre → Tek hücreli = Bakteri, Amip, Öglena  
→ Çok hücreli = Bitki, Hayvan  

b) Hücre yapısına göre → Prokaryot = Bakteri  
→ Ökaryot = Protista, Bitki, Mantar, Hayvan  

2: Beslenme *Enerji*  
- Ototrof - Heterotrof  

3: Solunum  
Besin $\xrightarrow{\text{solunum}}$ enerji  
O₂'li O₂'siz  

4: Bapartım  
İdrar, ter, yaprak dökümü, nefes verme  

5: Hareket  
→ Pasif H. = Bitki, mantar  
→ Aktif H. = Hayvan, Tek hücreli  

6: Çreme  
* Bireysel olarak şart değil *  
Eşeyli Eşeysiz  

7: Organizasyon  
Hücre → Doku → Organ → Sistem → Canlı  
her canlıda yok  

8: Metabolizma  
Anabolizma (A) Katabolizma (K)  
- Yapım - Yıkım  
- Özdelleme - Yönlendirme  
- Sentez  

A > K → büyüyor A = K → yetişkin  
A < K → yaşlı  

9: Homeostazi  
İç denge → Tuz, Su, Isı  

10: Büyüme-Gelişme  
Kütle-Hacim Olgunlaşma  

11: Adaptasyon → Uyum sağlamak  

12: Uyarılara Tepki  
Vücudumuzun verdiği  
istemli ve istemsiz tepkiler
