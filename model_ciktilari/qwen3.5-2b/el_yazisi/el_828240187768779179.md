**l isim (ad)**
*   kökü → isim
*   görevi → etkilemek
    *   öf
        *   oda, canta, kalem, Alya

**l Sifat**
*   kökü → isim
*   görevi → ismi nitelemek, belirtmek
*   ismin önüne gelir
    *   öf
        *   güzel, airtkin, kısa, uzun, besinci

**l Zamir**
*   kökü → isim
*   görevi → ismin yerini tutar
    *   öf
        *   ben, benim, o, onlar, şu, bu

**l Zarf**
*   kökü → isim
*   görevi → fiil, fiilmsi, sıfat ettilmek
    *   öf
        *   güzel, büyük, hızlı, neden, niye

**l Edat**
*   kökü → isim
*   görevi → kelimeler arası ilgi kural
    *   öf
        *   ile, gibi, -e karşı, -den oturu

**l Başlaç**
*   kökü → isim
*   görevi → başlamak
    *   öf
        *   ve, ile, veya, latin, çünkü, de

**l ünlem**
*   görevi → duyu yansıtmak
    *   öf
        *   hist, haydi, vahvah, of, hay

**l fiil**
*   kökü → fiil
*   görevi → eylemleri belirtmek
    *   öf
        *   gelmek, gitmek, almak, atfetmek
