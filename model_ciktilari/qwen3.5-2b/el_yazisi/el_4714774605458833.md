1. Problemde **fazlası** diyorsa → **Toplama (+)**
2. Problemde **eksiği** diyorsa → **Çıkarma (-)**
3. Problemde **katı** diyorsa → **Çarpma (×)**
4. Problemde **paylaşırlar** diyorsa → **Bölme (÷)**

---

**fazlası** → +  
**eksiği** → -  
**katı** → ×  
**paylaşırlar** → ÷
