# Cümlenin Ögeleri

1- Yüklem: iş,oluş,hareket bildiren öge

2- Özne: Cümlenin yüklemimde belirtilen işi, oluşu,hareketi,durumu yerine getiren ögedir.

a)gerçek özne
İşi yapan kişinin açıkça belli olduğu özneler denir.

b)sözde özne
Yüklemın belirttıgı işten etkilenen varlıgın, özne görevini üstlenmesidir.

c)gizli özne
Öznenin cümlede verilmemesi ama yükleme "kim?"sorulunca öznenin bellı oldugu özne türü.

3-Nesne

Belirtili Nesne
→Kimi
→Neyi
→Nereyi

Belirtisiz Nesne
→Ne

Cümlede öznenin yaptıgı işten Etkilenen öge,nesnedir.

→Yüklemi; yönelme,bulurma,ayrılma yönünden tamamlayan ögelerdir. e/-de/-den
