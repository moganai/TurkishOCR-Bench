# SÖZCÜK TÜRLERİ

## isim (ad)

- kōku → isim

- görevi → etkilenmek

- Oda, Ganta, Kalem, Alya

## Sıfat

- kōku → isim

- görevi → ismi nitelemek, betrmek

- ismin onune gelir

- Güzel, Airkin, Kisa, Uzun, Besinci

## Zarf

- kōku → isim

- görevi → fiil, filmsi, Sıfat etkilemek

- Güzel, Büyük, Hızlı, Neden, Niye

## Edat

- kōku → isim

- görevi → Kelimeler arası ilgi kuras

- İk, Gibi, -e Karsı, -den Ötürü

## Başlaç

- kōku → isim

- görevi → başlamak

- Ve, ile, Veya, Lakin, Cünkü, de

## Unlem

- görevi → duysu yansıtmak

- Hist, Haydi, Vahvah, Of, Hay

## fiil

- kōku → fiil

- görevi → eylemleri belirtmek

- Selmek, Sitmek, Almak, Affelmek

- Zamir

- kōku → isim

- görevi → ismin yerini tutar

- Ben, Benim, O, Onlas, Sı, Bu
