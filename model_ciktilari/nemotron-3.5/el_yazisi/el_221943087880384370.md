# SATIR SONUNA SİĞMAYAN SÖZCÜKLER

<figure>
  <img src="placeholder" alt="Balık resimleri"/>
</figure>

Yazı yazarken satır sonuna sigmayan kelimeler hecelerinden bölünür Satır sonuna sigmayan kelimeleri kısça çizgi (-) kullanarak hecelerine ayırıp alt satıra yazılır.

Örnek:

<table>
  <tr>
    <td>tel- efon</td>
    <td>→ Yanlış</td>
  </tr>
</table>

<table>
  <tr>
    <td>te- lefon</td>
    <td>→ Doğru</td>
  </tr>
</table>

<table>
  <tr>
    <td>tele- fon</td>
    <td>→ Doğru</td>
  </tr>
</table>

Kelimeler satır sonunda veya satır başında tek harf olarak şekilde bölünmez.

Örnek:

<table>
  <tr>
    <td>O- kulum</td>
    <td>→ Yanlış</td>
  </tr>
</table>

<table>
  <tr>
    <td>okul- lum</td>
    <td>→ Doğru</td>
  </tr>
</table>

<table>
  <tr>
    <td>elmay- ı</td>
    <td>→ Yanlış</td>
  </tr>
</table>

<table>
  <tr>
    <td>elma- yı</td>
    <td>→ Doğru</td>
  </tr>
</table>

Kesme işareti satır sonuna gelirse sadece kesme işareti kullanılır, kısa çizgi kullanılmaz.

Örnek:

<table>
  <tr>
    <td>Denizli- nin</td>
    <td>→ Yanlış</td>
  </tr>
</table>

<table>
  <tr>
    <td>Denizli'nin</td>
    <td>→ Doğru</td>
  </tr>
</table>
