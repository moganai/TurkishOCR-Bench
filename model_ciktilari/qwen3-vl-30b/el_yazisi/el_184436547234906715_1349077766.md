# Cümlemin Ögeleri

1- Yükleme: iş, olus, hareket bildiren öge

2- Özne: Cümlemin yükleminden belirtilen işi, olus, hareketi, durumu yerine getiren ögedir.

a) Gerçek özne

İşi yapan kişinin açıkça belli olduğu öznelerde denir.

b) Sözdə özne

Yüklemenin belirttiği işten etkilenen varlığın, özne görevini üstlenmesidir.

c) Gizli özne

Öznenin cümlede verilmemesi ama yükleme "kim?" sorulunca öznenin belli olduğu özne türü.

3- Nesne

Belirtili Nesne → Kimi  
→ Neyi  
→ Nereyi

Belirtisiz Nesne → Ne

Cümlede öznenin yaptığı işten etkilenen öge, nesnedir.

4- Yer tamlayıcısı

→ Yüldemi; yöneme, buluma, ayrılma yönünden tamamlayan ögelerdir. e/-de/-den

5- Zarf tamlayıcısı

→ Yüldemi; durum, azlık-çokluk, yer-yön bakımından tamamlayan ögelerdir.
