# Cümlenin Ögeleri
1-Yüklem: iş, oluş, hareket bildiren öge
2-Özne: Cümlenin yükleminde belirtilen işi, oluşu, hareketi, durumu yerine getiren ögedir.
a) gerçek özne
İşi yapan kişinin açıkça belli olduğu öznelere denir.
b) sözde özne
Yüklemin belirttiği işten etkilenen varlığın, özne görevini üstlenmesidir.
c) gizli özne
Öznenin cümlede verilmemesi ama yükleme "kim?" sorulunca öznenin belli olduğu özne türü.
# 3-Nesne
Belirtili Nesne
→ Kimi
Belirtisiz Nesne
→ Ne
→ Neyi Cümlede öznenin yaptığı işten etkilenen öge, nesnedir.
→ Nereyi
# 4-Yer tamlayıcısı
→Yüklemi; yönelme, bulunma, ayrılma yönünden tamamlayan ögelerdir. -e/-de/-den
# 5-Zarf tamlayıcısı
→Yüklemi; durum, azlık-çokluk, yer-yön bakımından tamamlayan ögelerdir.
