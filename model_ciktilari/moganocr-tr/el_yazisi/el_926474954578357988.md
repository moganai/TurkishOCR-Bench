# Canlıların ortak özellikleri
1: Hücresel Yapı
a) Hücre sayısına göre
Tek hücreli = Bakteri, Amip, Öglena
Çok hücreli = Bitki, Hayvan
b) Hücre yapısına göre
Prokaryot = Bakteri
Ökaryot = Protista, Bitki, mantar, Hayvan
2: Beslenme *Enerji*
- Ototrof - Heterotrof
3: Solunum
Besin solunum enerji
$O_2$'li $O_2$'sız
4: Boşaltım
İdrar, ter, yaprak dökümü, nefes verme
5: Hareket
Pasif H. = Bitki, mantar
Aktif H. = Hayvan, Tek hücreli
6: Çeşme *Bireysel olarak şart değil*
Eşeyli Eşeysiz
7: Organizasyon
Hücre -> Doku -> Organ -> Sistem -> Canlı her canlıya yok
8: Metabolizma
Anabolizma (A) Katabolizma (K)
- Yapım - Özdöneme - Sentez - Yıkım - Yadımlama
$A > K$ -> büyüyor $A = K$ -> yetişkin $A < K$ -> yaşlı
9: Homeostazi
İç denge -> Tuz, Su, Isı
10: Büyüme - Gelişme Kütle - Hacim Olgunlaşma
11: Adaptasyon -> Uyum sağlamak
12: Uyarılara Tepki Vücudumuzun verdiği işlemli ve istemsiz tepkiler Biyoloji Kimyasal Fiziksel Uyarı
