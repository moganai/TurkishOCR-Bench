# SATIR SONUNA SIĞMAYAN SÖZCÜKLER
Yazı yazarken satır sonuna sığmayan kelimeler hecelerinden bölünür. Satır sonuna sığmayan kelimeleri kısa çizgi (__) kullanarak hecelerine ayırıp alt satıra yazarız.
Örnek: _____ telefon → Yanlış
_____ telefon → Doğru _____ telefon → Doğru
Kelimeler satır sonunda veya satır başında tek harf olacak şekilde bölünmez.
Örnek: _____ o kulum → Yanlış _____ okulum → Doğru
_____ elmay → Yanlış _____ elma yı → Doğru
Kesme işareti satır sonuna gelirse sadece kesme işareti kullanılır. kısa çizgi kullanılmaz.
Örnek: _____ Denizli'nin → Yanlış _____ Denizli'nin → Doğru
