# Gen: Bir özelliğe ait bilgiyi taşıyan DNA parçasıdır.
# ÖR: Cinsiyet geni, göz rengi geni, saç rengi geni....

# Allel Gen: Biri anneden, biri babadan gelen aynı özelliği oluşturan genlerdir.

# Baskın (Dominant) Gen: Etkisini her durumda ortaya çıkaran genlerdir.

# Çekinik (Resesif) Gen: Baskın genle birlikteyken etkisini ortaya çıkaramayan genlerdir.
# ! Çekinik genler küçük harfle gösterilir.

# Saf (Homozigot-Ar.) Döl: Anne ve babadan allellerin aynı olmasıdır. ÖR: AA, bb, UU ...

# Melez (Heterozigot) Döl: Allel genlerin farklı olmasıdır.
# ÖR: Aa, Bb, Uu

# Fenotip: Canlıların dış görünüş özellikleridir.

# Genotip: Canlıların sahip olduğu genetik bilgidir, genler toplamı.

# Karakter: Canlıların genetik olarak sahip olduğu her özellik.
# ÖR: Saç [okunaksız], rengi, cinsiyet, çiçek rengi....
