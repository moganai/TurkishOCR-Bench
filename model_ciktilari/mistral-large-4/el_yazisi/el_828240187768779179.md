# SÖZCÜK TÜRLERİ
</header>

# İsim (ad)
- kökü → isim
- görevi → etkilenmek
- örn: Oda, çanta, kalem, Alya

# Sıfat
- kökü → isim
- görevi → ismi nitelemek, belirtmek
- ismin önüne gelir
- örn: güzel, çirkin, kısa, uzun, besinci

# Zamir
- kökü → isim
- görevi → ismin yerini tutar
- örn: ben, benim, o, onun, şu, bu

# Zarf
- kökü → isim
- görevi → fiil, fiilimsi, sıfat etkilemek
- örn: güzel, büyük, hızlı, neden, niye

# Edat
- kökü → isim
- görevi → kelimeler arası ilgi kurar
- örn: ile, gibi, -e karşı, -den ötürü

# Bağlaç
- kökü → isim
- görevi → bağlamak
- örn: ve, ile, veya,lakin, çünkü, de

# Ünlem
- görevi → duygu yansıtmak
- örn: hist, haydi, vah vah, of, hay

# Fiil
- kökü → fiil
- görevi → eylemleri belirtmek
- örn: gelmek, gitmek, almak, affetmek
