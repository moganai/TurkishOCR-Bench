Yazı yazarken satır sonuna sığmayan kelimeler hecelerinden bölünür. Satır sonuna sığmayan kelimeleri kısa çizgi (—) kullanarak hecelerine ayırıp alt satıra yazarız.

Örnek: tel— / efon → Yanlış

te— / lefon → Doğru &nbsp;&nbsp;&nbsp; tele— / fon → Doğru

<figure>
<figcaption>Balık çizimi</figcaption>
</figure>

Kelimeler satır sonunda veya satır başında tek harf olacak şekilde bölünmez.

Örnek: o— / kulum → Yanlış &nbsp;&nbsp;&nbsp; oku— / lum → Doğru

elmay— / yı → Yanlış &nbsp;&nbsp;&nbsp; elma— / yı → Doğru

</figure>

Kesme işareti satır sonuna gelirse sadece kesme işareti kullanılır, kısa çizgi kullanılmaz.

Örnek: Denizli'— / nin → Yanlış &nbsp;&nbsp;&nbsp; Denizli' / nin → Doğru
