# SATIR SONUNA SİĞMAYAN SÖZCÜKLER

<figure/>

Yazı yazarken satır sonuna sığmayan kelimeler hecelerinden bölünür. Satır sonuna sığmayan kelimeleri kısa çizgi ( _ ) kullanarak hecelerine ayırıp alt satıra yazarız.

Örnek:

<table>
<tr>
<td>..... tel _<br>efon</td>
<td>\(\rightarrow\) Yanlış</td>
</tr>
</table>

<table>
<tr>
<td>..... te _<br>lefon</td>
<td>\(\rightarrow\) Doğru</td>
<td>..... tele _<br>fon</td>
<td>\(\rightarrow\) Doğru</td>
</tr>
</table>

<figure/>

Kelimeler satır sonunda veya satır başında tek harf olacak şekilde bölünmez.

Örnek:

<table>
<tr>
<td>..... o _<br>kulum</td>
<td>\(\rightarrow\) Yanlış</td>
<td>..... okul _<br>lum</td>
<td>\(\rightarrow\) Doğru</td>
</tr>
</table>

<table>
<tr>
<td>..... elmay _<br>ı</td>
<td>\(\rightarrow\) Yanlış</td>
<td>..... elma _<br>yı</td>
<td>\(\rightarrow\) Doğru</td>
</tr>
</table>

<figure/>

Kesme işareti satır sonuna gelirse sadece kesme işareti kullanılır, kısa çizgi kullanılmaz.

Örnek:

<table>
<tr>
<td>..... Denizli ' _<br>nin</td>
<td>\(\rightarrow\) Yanlış</td>
<td>..... Denizli '<br>nin</td>

</tr>
