# Canlıların ortak özellikleri

1: Hücresel yapı
a) Hücre sayısına göre
-> Tek hücreli = Bakteri, Amip, Öglena
-> Çok hücreli = Bitki, Hayvan
b) Hücre yapısına göre
-> Prokaryot = Bakteri
-> Ökaryot = Protista, Bitki, mantar, hayvan

2: Beslenme *Enerji*
- Ototrof - Hetetrof

3: Solunum
Besin -> Solunum -> Enerji
$O_2$'li $O_2$'siz

4: Boşaltım
idrar, ter, Yaprak dökümü, Nefes verme

5: Hareket
-> Pasif H. = Bitki, mantar
-> Aktif H. = Hayvan, Tek hücreli

6: Çreme *Bireysel olarak şart değil*
Eşeyli Eşeysiz

7: Organizasyon
Hücre -> Doku -> Organ -> Sistem -> Canlı
her canlıca yok

8: Metabolizma
Anabolizma (A) Kataabolizma (K)
- Yapım - Yıkım
- özümleme - Yadımlama
- Sentez
A > K -> büyüyor A = K -> yetişkin
A < K -> yaşlı

9: Homeostazi
İç denge -> Tuz, Su, Isı

10: Büyüme - Gelişme
Kütle - Hacim Olgunlaşma

11: Adaptasyon -> Uyum sağlamak

12: Uyarılara Tepki Vücudumuzun verdiği
istemli ve istemsiz tepkiler
Biyolojik
