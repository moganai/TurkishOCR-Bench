# Sözcük Türleri

## İsim (ad)
- kökü → isim  
  - **görevi** → etkilemek  
    - **oda**, **çanta**, **kalem**, **Alya**

- katı → isim  
  - **görevi** → ismi nilememek, birbirine bak  
    - **ismin önüne gelir**  
    - **güzel**, **girkin**, **kaş**, **uçun**, **besinci**

- tamir → isim  
  - **görevi** → ismi yerini tutar  
    - **ben**, **benim**, **o**, **onlar**, **şu**, **bu**

- bağa → isim  
  - **görevi** → bağlamak  
    - **ve**, **ile**, **veya**, **lakin**, **cünkü**, **de**

- katı → isim  
  - **görevi** → düşürmüş, **katı** etmek  
    - **güzel**, **beyçik**, **hızlı**, **meden**, **niye**

- Edat → isim  
  - **kökü** → isim  
    - **görevi** → kelimeler arası **i**yi kurar  
    - **ik**, **gibi**, **-e** taraflı, -den önü

- fil → isim  
  - **kökü** → **fül**  
    - **görevi** → eylemleri belirtmek  
    - **gelmek**, **sürmek**, **almak**, **afl etmek**

- Ünlem → düşürmek  
  - **hızlı**, **haydi**, **vahvah**, **af**, **hıy**
