# Cümlenin Ögeleri

1- **Yükleme**: ısı, oluş, hareket bildiren öge  
2- **Özne**: Cümlenin yüklemede belirtilen işi, oluşu, hareketi, durumu yerine getiren ögedir.  
   - **gerek özne**  
    Ġsı yapan kişinin açıkça belli olduğu öznelerden.  
   - **sözlü özne**  
    Yüklemin belirttiği işten ettikten varılgın, özne görevini üstlenmesidir.  
   - **gözü özne**  
    Öznenin cümlede verilmemesi ama yükleme.  
    **Kim***"sorulunca** öznenin belli olduğu özne türü.  

3- **Nesne**  
   - **Belirtili Nesne**  
    →Kimi  
    →Ne  
   - **Belirtisiz Nesne**  
    →Ne  
   - **Cümlede öznenin yapısı**  
    **işten**  
    **öğrenir, nesnedir.**  

4- **Yer tamlayıcısı**  
   - **Yükleme**: yönelme, batımı, aynıca yönülen tamamlayan ögelerdir.  
    **e/de/den**  

5- **Zarf tamlayıcısı**  
   - **Yükleme**: durum, azık-çokluk, yer-yön (batımından tamamlayan ögelerdir).  
    **Nereye**  
    **Ne tabar**  
    **Necin**  
    **Ne şekilde**  
    **Kime**  
    **Nesin**  
    **Neytle**  
    **Kim**  
    **İçin**
