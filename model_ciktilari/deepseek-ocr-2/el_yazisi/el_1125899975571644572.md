# POLÍNOM

\[ \text{der } [P(x)] = m \]  
\[ \text{der } [Q(x)] = n \]  
\[ m > n \]  

\[ \text{der } [P(x) \cdot Q(x)] = \text{der } (x^m \cdot x^n) = m \cdot n + \text{der } (x^{m+n}) \]  
\[ \text{der } [P^n(x)] = 0 \]  
\[ \text{der } (x^m \cdot x^n) = 2m + 2n \]  

\[ \text{der } [P(x) + Q(x)] = \text{der } (x^m + x^n) = m \cdot (\text{der } (x^{m-1})) \]  

\[ \text{der } \left( \frac{P(x)}{Q(x)} \right) = \frac{\text{der } (P(x))}{\text{der } (Q(x))} = \frac{m}{n} \]
